AquaLife Ecommerce API URL Reference

Base URL: http://localhost:3000/api/v1

Authentication
--------------
POST /auth/register  Public   Create account and receive JWT token
POST /auth/login     Public   Login and receive JWT token
GET  /auth/me        Private  Get current user
POST /auth/logout    Private  Clear auth cookie

Protected requests require:
Authorization: Bearer <token>

Register body
-------------
{
  "fullName": "Kiran Rana",
  "email": "kiran@example.com",
  "username": "kiranr",
  "password": "password123",
  "phoneNumber": "+9779801234567",
  "profilePicture": "default-profile.png"
}

Login body
----------
{
  "email": "kiran@example.com",
  "password": "password123"
}

Login/register response
-----------------------
{
  "success": true,
  "token": "jwt-token",
  "data": {
    "id": "user-id",
    "_id": "user-id",
    "fullName": "Kiran Rana",
    "email": "kiran@example.com",
    "username": "kiranr",
    "phoneNumber": "+9779801234567",
    "profilePicture": "default-profile.png",
    "role": "user"
  }
}

Start server
------------
cd Aqua_life_api
npm run dev
